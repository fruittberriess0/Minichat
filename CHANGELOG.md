# История изменений MiniChat

## 4.1.0 — 2026-11-01

### Общение и надёжность
- Раздельные статусы «отправлено», «доставлено» и «прочитано» с подтверждением от клиента получателя.
- Очередь текстовых сообщений сохраняется на устройстве отдельно для каждого аккаунта. Повторная отправка использует тот же UUID и не создаёт дубликат при потере ответа сервера.
- Переподключение Realtime с задержкой, обновление пропущенных сообщений и автоматический повтор отправки.
- Удаление неотправленного сообщения из очереди.
- Поиск в полной истории открытого чата, экспорт всей доступной переписки и устойчивая подгрузка сообщений с одинаковым временем.
- Закреплённое сообщение находится отдельно от последней страницы истории.
- Срок жизни от пяти минут до семи дней; скрытие по таймеру и запрет чтения просроченных строк через API.

### Общее пространство
- Общие редактируемые заметки, задачи, опросы и обратный отсчёт до даты и времени.
- Крестики-нолики: поочерёдные ходы, проверка версии партии и победителя на сервере.
- Виселица: поочерёдные буквы, шесть ошибок, загаданное слово хранится вне доступной клиентам схемы.
- Совместный просмотр YouTube: присоединение в панели, общие кнопки воспроизведения, паузы и перехода к секунде.
- Изменения общего пространства приходят через Realtime; периодическая загрузка служит запасным способом обновления.

### Телефон, оформление и PWA
- Панель действий с прокруткой и двухрядное поле ввода на узком экране.
- ↑ в пустом поле редактирует последнее своё текстовое сообщение; Esc закрывает ответ и панели.
- Свой цвет пузырей с подбором цвета текста и свои локальные обои для каждого чата.
- Вибрация новых сообщений, анимация отправки и учёт настройки уменьшения движения.
- PNG-иконки 192/512, предварительное сохранение файлов приложения для офлайн-запуска, раздельные кэши версий.
- Push открывает нужную переписку; функция отправки по-прежнему требует VAPID и webhook.

### Разработка
- Ветка dev и проверки CI для неё; CHANGELOG и актуальные инструкции запуска.
- Lockfile, исправленная библиотека Supabase, модульные проверки очереди и экспорта.
- Локальная PostgreSQL для проверок миграций, доступа двух участников и отказов постороннему.
- Проверки браузера для переписки, восстановления очереди и мобильного общего пространства.
- Превью Vercel не собирается с резервными реквизитами рабочей базы.
- Совместимость первой миграции с существующим параметром check_chat_id функции is_chat_member.

Серверные изменения подготовлены в SQL. Они не применяются к рабочей базе при публикации исходного кода.
