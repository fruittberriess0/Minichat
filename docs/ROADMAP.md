# Запуск MiniChat 4.1

Исходники, сервер и интерфейс проверены на отдельном minichat-dev. Подробности: [VERIFICATION.md](VERIFICATION.md), функции: [FEATURES.md](FEATURES.md), изменения: [CHANGELOG.md](../CHANGELOG.md).

В тестовом окружении развёрнуты база, private Storage, Realtime, функции push и удаление по расписанию. Переменные Vercel Preview относятся только к ветке dev и отдельной базе. Подтверждены реальные запросы и действия двух пользователей в браузере.

Осталось сохранить адрес возврата email-входа в Supabase Auth и проверить получение push на физическом устройстве после выдачи разрешения. Перенос в рабочую базу выполняется после сохранения резервной копии переписки и согласования этого экспорта с владельцем.

Миграции применяются по порядку имён. Пустому проекту сначала нужен bootstrap-dev.sql. Затем исходные миграции 001–006, chat_completion, runtime_storage_and_push и runtime_authorization. В рабочую базу bootstrap-dev.sql применять нельзя.

Текущий проект уже разбит на HTML, CSS и JavaScript-модули и использует Vite. Вариант полностью без сборки требует отдельного изменения способа подключения библиотек и конфигурации окружений.
